Command Line Options

LeoCAD can be used to generate images or export files from the command line.

$ leocad [options] [file]

Rendering settings such as image size and shading use saved preferences unless overridden. Image backgrounds are independent of the viewport background preference: formats that preserve alpha, such as PNG, default to transparent; other formats, such as JPEG, default to white.

All color options accept RRGGBB or RRGGBBAA, with alpha last and defaulting to FF (opaque), or transparent. A leading # is optional. Bare hex is convenient in shell scripts; quote colors with a # prefix, such as "#FF000080".

For example, FF000080 is red with about 50% opacity. Eight-digit colors use this RGBA order for backgrounds, fades, highlights, and stud and edge colors.

Examples

leocad model.ldr --image model.png
leocad model.ldr --image model.jpg --background FFFFFF
leocad model.ldr --image model.png --background FF000080
leocad model.ldr --image model.png --background-gradient FF0000FF 0000FF00

Options

-l, --libpath <path>

Set the Parts Library location to path.

-i, --image <outfile.ext>

Save a picture in the format specified by ext and exit. The output filename is optional; if omitted, it is based on the input filename and the image extension in preferences. An explicit filename without an extension is written as PNG. Place the input filename before --image when omitting the output filename.

--background <color>

Set a solid image background or use transparent. Requires --image.

--background-gradient <top> <bottom>

Set a vertical image background gradient using two colors. Each endpoint can have its own alpha. Requires --image.

Background options cannot be combined or repeated. Formats that do not preserve alpha require an opaque background and reject transparent or colors with alpha below FF.

-w, --width <width>

Set the picture width.

-h, --height <height>

Set the picture height.

-f, --from <step>

Set the first step to save pictures (steps start at 1).

-t, --to <step>

Set the last step to save pictures.

-s, --submodel <submodel>

Set the active submodel.

-c, --camera <camera name>

Set the active camera.

--viewpoint <viewpoint>

Set the view to one of the preset viewpoints (front, back, left, right, top, bottom, home).

--camera-angles <latitude> <longitude>

Set the camera angles in degrees around the model (each between -360 and 360).

--camera-position <x> <y> <z> <tx> <ty> <tz> <ux> <uy> <uz>

Set the camera position, target and up vector.

--camera-position-ldraw <x> <y> <z> <tx> <ty> <tz> <ux> <uy> <uz>

Set the camera position, target and up vector using LDraw coordinates.

--orthographic

Render images using an orthographic projection.

--fov <degrees>

Set the vertical field of view used to render images.

--zplanes <near> <far>

Set the near and far clipping planes used to render images (1 ≤ near < far).

Named cameras take precedence over the other camera controls; otherwise, viewpoint takes precedence over angles, which take precedence over an explicit position.

--fade-steps

Render parts from prior steps faded.

--no-fade-steps

Do not render parts from prior steps faded.

--fade-steps-color <color>

Rendering color for prior step parts.

--highlight

Highlight parts in the steps they appear.

--no-highlight

Do not highlight parts in the steps they appear.

--highlight-color <color>

Rendering color for highlighted parts.

--shading <mode>

Select shading mode for rendering (wireframe, flat, default, full).

--line-width <width>

Set the width of the edge lines (0 to 10).

--aa-samples <samples>

Anti-aliasing sample size (1, 2, 4, or 8).

-ss, --stud-style <style>

Set the stud style (0=No style, 1=LDraw single wire, 2=LDraw double wire, 3=LDraw raised floating, 4=LDraw raised rounded, 5=LDraw subtle rounded, 6=LEGO no logo, 7=LEGO single wire).

-nscc, --disable-stud-cylinder-color

Disable high contrast stud cylinder color.

-scc, --stud-cylinder-color <color>

High contrast stud cylinder color.

-nec, --disable-edge-color

Disable high contrast edge color.

-ec, --edge-color <color>

High contrast edge color.

-nbec, --disable-black-edge-color

Disable high contrast edge color for black parts.

-bec, --black-edge-color <color>

High contrast edge color for black parts.

-ndec, --disable-dark-edge-color

Disable high contrast edge color for dark color parts.

-dec, --dark-edge-color <color>

High contrast edge color for dark color parts.

-aec, --automate-edge-color

Enable automatically adjusted edge colors. This takes precedence over manual edge colors; high contrast stud-cylinder settings still apply.

-cc, --color-contrast <contrast>

Color contrast value between 0.0 and 1.0. Requires automatic edge colors.

-ldv, --light-dark-value <value>

Light/Dark color value between 0.0 and 1.0. Used by automatic edge colors or as the dark-color threshold for high contrast stud styles.

Stud-cylinder and manual edge color options require a high contrast stud style (6 or 7).

-obj, --export-wavefront <outfile.obj>

Export the model to Wavefront OBJ format. The output filename is optional.

-3ds, --export-3ds <outfile.3ds>

Export the model to 3D Studio 3DS format. The output filename is optional.

-dae, --export-collada <outfile.dae>

Export the model to COLLADA DAE format. The output filename is optional.

-csv, --export-csv <outfile.csv>

Export the list of parts used in CSV format. The output filename is optional.

-html, --export-html <folder>

Create an HTML page for the model. The output folder is optional.

-v, --version

Output version information and exit.

-?, --help

Display help message and exit.
